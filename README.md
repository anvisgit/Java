# Java

A collection of small Java programs written while brushing up on the language and solving problems.
This repository is primarily a collection of small problem solving exercises drawn from:
- [FreeCodeCamp — Daily Coding Challenge](https://www.freecodecamp.org/learn/daily-coding-challenge/archive)
- [Rosetta Code](https://www.rosettacode.org/wiki/Rosetta_Code)

## Why this repository exists

This is partly a Java refresher. I am revisiting the language because i have nothing better too do. This repository was never intended to demonstrate advanced Java-- atleast not in the forseeable future. Thus no object-oriented architectures, Spring applications, concurrency frameworks, JVM internals, or other such declarations of adulthood here. The problems are deliberately small.

I kust enjoy coding in Java. This repository is therefore less about proving that I know Java and more about spending time writing it.There is no particular framework or grand architectural vision here.
